# Prompts Used

## Primary Prompt (used for all 10 AI systems)

```
Design a comprehensive AGI (Artificial General Intelligence) system architecture. Your proposal should address:

1. **Core Architecture**: What is the fundamental computational paradigm? (e.g., neural-symbolic hybrid, pure neural, cognitive architecture, etc.)

2. **Knowledge Representation**: How does the system store, retrieve, and reason over knowledge? Include mechanisms for both declarative and procedural knowledge.

3. **Learning & Adaptation**: How does the system learn from experience? Address:
   - Few-shot and zero-shot learning
   - Transfer learning across domains
   - Continual learning without catastrophic forgetting
   - Self-improvement mechanisms

4. **Reasoning & Planning**: How does the system:
   - Perform deductive, inductive, and abductive reasoning
   - Plan multi-step actions
   - Handle uncertainty and probabilistic reasoning
   - Perform counterfactual reasoning

5. **Memory Architecture**: Describe the memory subsystem including:
   - Working memory
   - Episodic memory (personal experiences)
   - Semantic memory (general knowledge)
   - Procedural memory (skills)

6. **Perception & Action**: How does the system interface with the world?
   - Multi-modal input processing
   - Action generation
   - Embodiment considerations (if any)

7. **Meta-cognition**: How does the system:
   - Monitor its own cognitive processes
   - Know what it doesn't know (uncertainty awareness)
   - Allocate computational resources
   - Self-correct errors

8. **Safety & Alignment**: How is the system kept safe and aligned?
   - Value learning mechanisms
   - Interpretability features
   - Containment strategies
   - Corrigibility (ability to be corrected)

9. **Scalability**: How does the architecture scale?
   - Computational requirements
   - Training efficiency
   - Real-time performance

10. **Novel Contributions**: What makes your proposed architecture unique or innovative?

Please be as specific and technical as possible. Use diagrams (ASCII or described) where helpful. Propose concrete mechanisms rather than abstract principles.
```

## Notes on Prompt Variations

The primary prompt was used identically for all 10 AI systems. No adaptations were necessary as all systems support long-form technical output.
