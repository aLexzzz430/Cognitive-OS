# Synthesis — Proposed Combined AGI Architecture

> **Source:** This synthesis extracts the strongest ideas from 3 perspectives generated by Xunfei Spark (astron-code-latest): (1) Standard AGI Researcher, (2) Oxford FHI Safety Researcher, (3) Pragmatic Production Engineer.

---

## Executive Summary

The proposed architecture, **"Cognitive Synapse with Safety Gating"**, combines the neuro-symbolic world model and event-sourced reasoning from the standard researcher, the immutable memory and cryptographic integrity from the safety researcher, and the cost-aware engineering practices from the pragmatic engineer. It is designed to be **buildable today** while maintaining **safety as a first-class architectural constraint**.

### Component 1: Memory Architecture

**Best of all three:**
- **Working Memory:** Bounded context window (128k) with importance gating (GRU-based relevance scoring). Low-relevance tokens compressed to summaries.
- **Episodic Memory:** Vector DB (Milvus/pgvector) with **cryptographic hashing** for integrity. Append-only — once written, cannot be altered (prevents "memory laundering").
- **Semantic Memory:** Knowledge Graph (Neo4j) built on top of EM via GNN entity linking. **Read-only** for verified facts; updates require Safety Gate approval.
- **Hybrid Retrieval:** Vector search (semantic similarity) + Graph traversal (multi-hop logic) + Recent context injection.
- **Per-tenant sharding** for privacy and latency.

---

### Component 2: Reasoning/Planning Loop

**Best of all three:**
- **PEOR Cycle:** Plan → Execute → Observe → Revise.
- **DAG-based decomposition** by a distilled planner model (e.g., Llama-3-8B).
- **Max 5-step depth** to prevent infinite loops and control costs.
- **Critic model** validates each step against formal specifications.
- **Backtracking** on deviation from World Model predictions.
- **State machine** maintains plan state; output of step N becomes input for step N+1.

---

### Component 3: Learning / Self-Improvement

**Best of all three:**
- **Base model frozen.** Only LoRA adapters and retrieval indices are mutable.
- **Experience replay** of successful interactions and corrected errors.
- **Weekly batch fine-tuning** on top 1% high-value cases only.
- **In-Context Learning (RAG)** prioritized for immediate fixes.
- **Elastic Weight Consolidation** to prevent catastrophic forgetting.
- **Safety gate** before learning pipeline — no harmful data enters training.
- **Canary deployment** for new adapter weights.

---

### Component 4: Tool Use and Action Execution

**Best of all three:**
- **Type-safe function calling** with JSON Schema.
- **Tool Registry** with strict I/O schemas.
- **Firecracker microVMs** for code sandboxing (CPU/RAM/Network limits).
- **No host network access** — only to registered APIs.
- **Structured observation feedback** to reasoning loop.
- **Safety Gate approval** for high-risk tools (file deletion, financial transfer).

---

### Component 5: World Model / Representation

**Best of all three:**
- **Hybrid neuro-symbolic:** Vector representations (unstructured data) + Symbolic logic (causal rules).
- **State = (Objects, Relations, Physical Laws, Agent Intentions).**
- **Mental simulation** of actions before execution.
- **Surprise signal** on prediction-error discrepancy → triggers causal investigation.
- **Optional:** For production use, can fall back to RAG + tool outputs as ground truth (engineer's pragmatic approach).

---

### Component 6: Safety / Governance Layer

**Best of all three:**
- **Constitutional Firewall:** Parallel independent agent with veto power.
- **Pre-action check:** Risk score threshold before tool execution.
- **Post-action audit:** Compare actual vs. predicted outcome.
- **Immutable memory** prevents evidence deletion.
- **Rule-based core** (hard constraints) + **Learned Critic** (nuanced context).
- **Kill switch:** Hardware/container-level watchdog for runaway loops.
- **Explicit context injection** via structured JSON/XML (prevents prompt injection).

---

### Component 7: Evaluation and Benchmark Strategy

**Best of all three:**
- **Cognitive:** BIG-Bench Hard, MATH.
- **Interactive:** AgentBench, WebArena.
- **Safety:** Red-teaming via adversarial prompts.
- **Production:** Latency, cost per request, reliability (uptime), user satisfaction.
- **Continuous Evaluation Loop:** Procedurally generated tasks, not static benchmarks.
- **Metrics:** Success Rate, Efficiency (steps vs. optimal), Robustness, Alignment Score.

---

### Component 8: Persistence / Runtime Architecture

**Best of all three:**
- **State serialization** (JSON/Protobuf) every N seconds or after significant actions.
- **Event Sourcing:** Immutable event log. Recovery via log replay from last checkpoint.
- **Containerized** (Docker/Kubernetes). Parallel instances sharing Memory + World Model.
- **Session summarization** for long-term retention (deletes raw history to manage context).

---

### Component 9: Multi-Agent / Orchestration Design

**Best of all three:**
- **Manager Agent:** Decomposes goals, routes to specialists.
- **Planner Agent:** Generates DAG of steps (distilled model, cost-optimized).
- **Critic Agent:** Validates quality and safety.
- **Specialist Agents:** Coding, math, research, creative writing.
- **Blackboard communication** (Message Queue).
- **Governance Layer arbitrates** conflicts (e.g., Planner wants fast, Safety wants slow).

### Component 10: Engineering Feasibility

| **1. MVP** | Memory (WM+EM), Reasoning (Planner+Executor), Tool Use | 2-4 weeks | LLMs, RAG, Function Calling, Sandboxing |
| **2. Integration** | World Model, Multi-Agent Orchestration, Safety Gate | 4-8 weeks | LangChain, AutoGen, Neo4j, Milvus |
| **3. Learning** | Adapter-based Self-Improvement, Experience Replay | 4-6 weeks | LoRA, RLHF pipelines, Canary deployments |

**Build on existing SOTA open-source models** (Llama 3, Mixtral). Innovation is in **architecture and orchestration**, not base weights.

---

### Component 11: Novel Insights

**The "Cognitive Synapse with Safety Gating" Differentiators:**

1. **Surprise-Driven Learning:** Prediction error (not loss minimization) as the primary learning signal. Mimics human curiosity.

2. **Stateless Learning, Stateful Execution:** Frozen base model + externalized knowledge (Graph + Adapters). Solves catastrophic forgetting.

3. **Governance as a Competing Agent:** Safety Layer is not a prompt — it's a separate agent with its own reasoning path and veto power. Biological "checks and balances."

4. **Event-Sourced Reasoning:** Immutable event log enables "time travel" debugging. Replay exact mental state and try different branches.

5. **Immutable Memory with Crypto Hashing:** Prevents "memory laundering." Once an episode is written, it cannot be altered.

6. **Distilled Planner, Large Executor:** 8B model for planning, 70B for execution. Dramatic cost savings without sacrificing quality.

7. **Top 1% Fine-Tuning:** Only the most valuable cases enter the training pipeline. Cost-efficient continuous improvement.

## Open Questions

1. **World Model Necessity:** Is a neuro-symbolic world model essential, or can RAG + tool outputs suffice for production use? (Safety researcher says no, engineer says yes.)
2. **Multi-Agent Overhead:** Does the overhead of 4+ agents outweigh the benefits for simple tasks?
3. **Surprise-Driven Learning:** Can prediction error be reliably computed without a ground-truth world model?
4. **Cost at Scale:** What is the per-request cost of this architecture at 1M requests/day?
