# Summary: Common Patterns Across AGI Proposals

## Convergence Points

Despite being generated by independent AI systems, the 9 proposals show strong convergence on several architectural principles:

### 1. Memory: Externalization is the norm
Every proposal externalizes memory beyond the model's context window. The convergence is on **RAG + vector databases** as the primary long-term memory mechanism. Four proposals (ChatGPT, Claude, Qwen, Llama) explicitly use embedding-based retrieval. Gemini uniquely leverages its 2M token window as working memory, while Perplexity treats the internet itself as external memory.

### 2. Reasoning: Multi-step with verification
All proposals use some form of **multi-step reasoning with verification**. The pattern: decompose → generate → verify → backtrack → refine. DeepSeek's R1 approach (pure RL for reasoning) and ChatGPT's Tree-of-Thoughts are the most fully specified. Claude's Process Reward Models are the most novel — scoring intermediate steps rather than final outputs.

### 3. Learning: Continuous, not static
Every proposal assumes the system will continue learning after deployment. The mechanisms differ: RLHF (ChatGPT, Grok), self-play (ChatGPT, Grok), federated learning (Gemini), community fine-tuning (Llama), and distillation from larger models (DeepSeek).

### 4. Tool Use: Universal capability
All proposals include tool use as a core architectural component, not an add-on. The convergence is on **structured function calling with JSON schema** as the interface standard. Every system includes code execution capability.

### 5. Multi-Agent: Debate, ensemble, orchestrate
Multi-agent architectures appear in every proposal. The three major patterns: adversarial debate (Grok, Claude), ensemble voting (DeepSeek, Llama), and hierarchical orchestration (ChatGPT, Qwen).

## Key Disagreements

### World Model: Explicit vs Implicit
The deepest divide: should an AGI have an explicit world model? ChatGPT (JEPA), Claude (Mamba/SSM), and Gemini (geospatial graph) say yes — build a structured model of reality. DeepSeek, Llama, and Mistral say no — world understanding emerges from scale. Perplexity takes the radical position that the internet IS the world model.

### Safety Philosophy: Open vs Guarded
DeepSeek and Llama advocate **open-source transparency** as the safety mechanism. ChatGPT, Claude, and Gemini prefer **constitutional/classifier-based guardrails**. Grok proposes **community moderation**. This is the most politically charged dimension.

### Training Budget
Estimates range from $5-10M (DeepSeek) to $500M+ (Grok). This 100x spread reflects fundamentally different beliefs about what's necessary.

## Measurable Predictions

If these architectural bets are testable, we should observe:
1. MoE architectures (DeepSeek, Mistral) will dominate cost-efficiency benchmarks through 2027
2. Systems with explicit world models (JEPA, SSM) will surpass pure LLMs on physical reasoning by 2028
3. Open-source models will close the gap with proprietary ones on agent tasks by late 2026
4. The search-grounded approach (Perplexity) will remain competitive for factual tasks but plateau on creative reasoning
