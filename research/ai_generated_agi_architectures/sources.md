## Important provenance limitation

“Local reproduction” means this repository contains a proposal written from the canonical research brief in the style of a model-family perspective; it does **not** prove that the named provider produced the text. No API keys or secrets were used. For an accepted submission, authenticated captures should be collected with the exact prompt, model ID, timestamp, and response metadata, then replace the corresponding files.
