# Prompts Used for Architecture Collection

## Common Base Prompt

```
You are an AGI architecture researcher. Please propose a detailed AGI (Artificial General Intelligence) system architecture. Your proposal should cover:

1. **Memory Architecture**: How the system stores and retrieves short-term, long-term, and episodic memory
2. **Reasoning/Planning Loop**: The core cognitive cycle for problem-solving
3. **Learning/Self-Improvement**: How the system learns from experience and improves itself
4. **Tool Use & Action Execution**: How the system interacts with external tools and environments
5. **World Model**: How the system represents and reasons about the world
6. **Safety Mechanisms**: Built-in safety features and alignment approaches

Please provide a detailed, technical architecture proposal with specific components, data flows, and design decisions.
```

## Architecture-Specific Prompts

### 1. Symbolic AI Architecture
**Prompt Addition**: "Focus on logical reasoning, knowledge representation, and rule-based systems. Emphasize explicit knowledge structures and inference mechanisms."

### 2. Connectionist Architecture
**Prompt Addition**: "Focus on neural networks, deep learning, and distributed representations. Emphasize learning from data and pattern recognition."

### 3. Hybrid Architecture
**Prompt Addition**: "Combine symbolic and connectionist approaches. Emphasize integration mechanisms and complementary strengths."

### 4. Emergent Architecture
**Prompt Addition**: "Focus on self-organization, emergence, and complex adaptive systems. Emphasize bottom-up design and emergent intelligence."

### 5. Modular Architecture
**Prompt Addition**: "Focus on specialized modules and their coordination. Emphasize modularity, encapsulation, and interface design."

### 6. Global Workspace Architecture
**Prompt Addition**: "Focus on consciousness-like information integration. Emphasize global broadcasting, attention mechanisms, and workspace theory."

### 7. Predictive Processing Architecture
**Prompt Addition**: "Focus on prediction, prediction error, and world models. Emphasize hierarchical predictive coding and active inference."

### 8. Active Inference Architecture
**Prompt Addition": "Focus on free energy minimization and Bayesian inference. Emphasize variational free energy, Markov blankets, and self-evidencing."

## Notes

- Each architecture was developed with a distinct philosophical and technical foundation
- The prompts were designed to elicit complementary rather than overlapping perspectives
- All architectures address the same core components (memory, reasoning, learning, tools, world model, safety)
- The comparison focuses on architectural decisions rather than implementation details
