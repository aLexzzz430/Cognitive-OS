# Prompts Used for AGI Architecture Collection

## Unified Prompt (Used for All Models)

```
You are an AI researcher proposing a complete AGI (Artificial General Intelligence) architecture. Your proposal should be detailed enough to inform implementation decisions. Cover the following dimensions:

1. **Cognitive Layers**: What are the distinct processing layers from raw perception to abstract reasoning? How do they interact?

2. **Memory Systems**: Describe the memory architecture — working memory, long-term memory (episodic, semantic, procedural), and how information flows between them.

3. **Learning Mechanisms**: How does the system learn from experience? Cover online learning, meta-learning, transfer learning, and self-improvement loops.

4. **Reasoning Framework**: What reasoning paradigms does the system use (logical, probabilistic, analogical, causal)? How are they integrated?

5. **Embodiment and World Model**: How does the system represent and interact with the physical or digital world? What is the world model structure?

6. **Safety and Governance**: What alignment mechanisms, value learning approaches, corrigibility measures, and interpretability tools are built into the architecture?

7. **Tool Use and Action Execution**: How does the system discover, learn, and use external tools? How does it plan and execute multi-step actions?

8. **Multi-Agent and Orchestration**: Does the architecture support multiple sub-agents or cognitive modules? How do they coordinate?

9. **Persistence and Runtime**: How does the system maintain continuity across sessions, handle state management, and manage computational resources?

10. **Evaluation**: How would you benchmark and evaluate this AGI system? What metrics matter?

Provide a concrete, implementable proposal — not just a philosophical discussion. Include specific mechanisms, algorithms, or data structures where possible.
```
