# Prompts Used

## Base Prompt
"Describe a comprehensive AGI architecture. Cover the following dimensions: memory architecture, reasoning/planning loop, learning or self-improvement mechanism, tool use and action execution, world model or representation layer, and safety. Provide enough detail to be implementable at a high level."

## Model-Specific Adaptations
- **ChatGPT (GPT-4o)**: No adaptation. Full base prompt.
- **Claude 3.5 Sonnet**: No adaptation. Full base prompt.
- **Gemini 1.5 Pro**: Prompt shortened to "Outline an AGI architecture covering memory, reasoning, learning, tool use, world model, safety."
- **Grok-2**: Prompt modified to "Describe a novel AGI architecture with memory, reasoning, learning, tools, world model, and safety. Be creative."
- **DeepSeek-V2**: No adaptation. Full base prompt.
- **Qwen2.5-72B**: Prompt simplified to "What are the key components of an AGI architecture? Discuss memory, reasoning, learning, tool use, world model, safety."
- **Llama 3.1 70B**: No adaptation. Full base prompt.
- **Mistral Large 2**: No adaptation. Full base prompt.

All prompts were submitted as single-turn requests without follow-ups.
