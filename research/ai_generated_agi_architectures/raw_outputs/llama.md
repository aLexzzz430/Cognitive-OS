**Llama‑AGI Architecture (high‑level, <100 words)**  

1. **Unified Cognitive Core** – a transformer‑based, self‑supervised model that learns a shared latent space for language, perception, and reasoning, continuously updated via meta‑learning.  
2. **Dynamic Memory Graph** – a scalable, differentiable graph store that links episodic experiences, abstracts concepts, and supports rapid retrieval & causal inference.  
3. **Action‑Feedback Loop** – a modular interface that translates core outputs into motor, simulation, or API actions, receives real‑time sensory/utility feedback, and closes the learning loop.  

**Unique Feature:** *Self‑Generated Curriculum Engine* – the system autonomously designs progressive training tasks by detecting knowledge gaps in the Memory Graph and spawning targeted simulations, accelerating open‑ended skill acquisition.
