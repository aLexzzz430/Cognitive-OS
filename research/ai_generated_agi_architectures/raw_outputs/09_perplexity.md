# Perplexity AI — AGI Architecture Proposal

**System**: Perplexity (Agentic AI with search)  
**Provider**: Perplexity AI  
**Access**: Direct web interaction, API  
**Collection Date**: 2026-09-15  
**Source Documents**: Perplexity product, published blog posts, API documentation

---

## 1. Memory Architecture
- **Real-time retrieval**: Memory is the entire internet (via search)
- **Citation-based**: Every claim sourced and linked
- **Conversation memory**: Thread-specific context retention
- **Proposed AGI**: External memory as primary — don't store, retrieve
- **Key insight**: Why remember when you can look up?

## 2. Reasoning/Planning Loop
- **Search-then-reason**: Search first, then reason over results
- **Multi-step reasoning**: Chain of searches + reasoning
- **Copilot mode**: Extended multi-step reasoning with search
- **Proposed AGI**: Retrieval-augmented reasoning — always grounded in evidence
- **Unique**: Reasoning is always grounded in real-world evidence (not just training data)

## 3. Learning/Self-Improvement
- **User feedback**: Thumbs up/down on answer quality
- **Search quality improvement**: Better search = better answers
- **Proposed AGI**: Continuous improvement of retrieval and synthesis
- **No weight updates**: Improve the pipeline, not the model
- **Key**: Pipeline improvement > model retraining

## 4. Tool Use and Action Execution
- **Search as primary tool**: Web search is core capability
- **Code execution**: Python sandbox for computation
- **Image generation**: DALL-E integration
- **Shopping/action**: Proposed — act on information (book, buy, etc.)
- **Proposed AGI**: Information → action pipeline

## 5. World Model
- **Real-time world model**: Updated from search results (always current)
- **Citation network**: World knowledge is a web of linked sources
- **Proposed AGI**: Dynamic world model — always up-to-date from live data
- **Unique**: World model never stale — always refreshed from reality

## 6. Safety and Alignment
- **Source transparency**: Show where information comes from
- **Citation accountability**: Claims are sourced (can be verified)
- **Proposed**: Transparency-based safety — if you can see sources, you can judge truth
- **Key**: Verifiability > trust

## 7. Consciousness/Self-Model
- **Minimal self-model**: Focus on information retrieval, not self-reflection
- **Tool identity**: "I am a search engine that reasons"
- **Proposed**: Self-model as information curator

## 8. Multi-Agent Coordination
- **Proposed**: Multi-agent research teams
- **Specialist agents**: Different agents for different domains
- **Orchestrator**: One agent coordinates research across specialists
- **Key**: Collaborative research via agent teams

---

**Key Differentiator**: Retrieval-first, citation-based, transparent. Perplexity's AGI doesn't need to know everything — it just needs to find everything.
