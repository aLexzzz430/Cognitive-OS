Architecture for CoGNITIVE-OS

CoGNITIVE-OS is a local-first cognitive runtime pursuing general-purpose problem solving. The project aims to provide a practical next iteration that retains control over goals, budget, tools, and shutdown. The architecture is designed to be concise, modular, and flexible, allowing for easy extension and adaptation to new use cases.

Memory Architecture

The memory architecture is designed to be bounded observation-to-action loop with stopping criteria and recovery from failed plans. The loop is divided into three phases: observation, action, and observation. Observation is the initial state of the system, and action is the next state that the system will reach based on the current observation. The observation phase is responsible for gathering and storing observations, while the action phase is responsible for executing the action that is stored in the observation.
